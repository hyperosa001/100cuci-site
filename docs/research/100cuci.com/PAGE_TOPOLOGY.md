# 100cuci.com Page Topology

Target: https://100cuci.com/
Viewport: Mobile-first (380-390px primary)

## Sections (top to bottom)

1. **App Download Banner** — Fixed GIF banner at top
2. **Site Header** — Logo + Login/Register buttons + ticker marquee
3. **Banner Carousel** — Splide carousel with promotional banners + static banner
4. **Live Transactions** — Real-time deposit/withdraw table (time-driven updates on original)
5. **Referral Panel** — Rebate banner + Share/Downline/Copy/Free Bot buttons + commission info
6. **Account Panel** — VIP rank, balance, deposit/withdraw/refresh
7. **Sports Section** — Upcoming sports matches with odds
8. **Hot Games** — Horizontal swiper of game thumbnails
9. **Site Tabs** — VIP Ranking, Leaderboard, Cuci King, Soccer, etc.
10. **Welcome CTA** — Register now section
11. **SEO Content** — Long-form article content + FAQ
12. **Footer** — Copyright + sister site links
13. **Bottom Nav** — Fixed mobile navigation (Home, History, Promo, Live Chat, Setting)

## Interaction Models

- Banner carousel: time-driven auto-advance
- Hot games: horizontal scroll (touch/drag)
- Bottom nav: click-driven navigation
- Modal popups: click-driven (partnership promos on load)
- Live transactions: time-driven data refresh
