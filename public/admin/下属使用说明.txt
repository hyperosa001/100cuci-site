100CUCI 内容后台说明
================================

【栏目文章】请用 WordPress（不要用本页发栏目文）
详见项目文档：docs/WORDPRESS_CMS.md

1. 登录 WordPress 后台
2. 写文章 → 勾选分类（casino / slots / sportsbook / lottery / promotions）
3. 发布 → 约 1 分钟后出现在 https://www.100cuci.ad

【本页 /admin 仍可改】
- 站点按钮链接 → Register / Login
- 主页 SEO → 首页底部文章与 FAQ

登录本页：
1. 打开：https://www.100cuci.ad/admin
2. GitHub 登录（弹出小窗口授权）
3. 改完点 Publish → 等 2～3 分钟部署
