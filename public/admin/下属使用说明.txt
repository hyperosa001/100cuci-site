100CUCI 内容后台 — 下属使用说明
================================

1. 打开：https://www.100cuci.ad/admin
2. 登录 GitHub（二选一）：
   - 优先：点页面底部「GitHub 登录（推荐）」
   - 或：点 CMS 里的「Login with GitHub」
3. 若浏览器提示「拦截弹出窗口」→ 点允许，然后重试
4. 在弹出的小窗口里完成 GitHub 授权，小窗口会自动关闭
5. 用公司给的 GitHub 账号，并在邮件/GitHub 通知里 Accept 仓库邀请
6. 左侧选要改的内容 → 改完点 Publish → 等 2～3 分钟部署

可改内容：
- 站点按钮链接 → Register / Login 跳转地址
- 主页 SEO → 首页底部文章与 FAQ
- 栏目文章 → 各栏目下的文章

注意：
- 必须用 https://www.100cuci.ad/admin
- 不要用「当前窗口跳转」—— 必须用弹出小窗口完成登录
- 新文章 slug 用英文小写+连字符，例如 my-new-article
- 不要改已有文章的 slug，否则旧链接会 404
